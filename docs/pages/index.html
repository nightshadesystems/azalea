Azalea

Web management UI for VyOS. One Debian package, one Rust daemon.
curl -fsSL https://nightshadesystems.github.io/azalea/install.sh | sudo bash

Then open https://<router>:8443 and sign in with a VyOS local user.

Source, releases and the signing key: github.com/nightshadesystems/azalea

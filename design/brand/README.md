# Azalea logo kit

Mark: five-petal bloom. Violet #A78BE8 (on dark) / #7658BC (on light). Wordmark: Archivo Bold, "Azalea", letter-spacing -0.015em.

- azalea-mark.svg / azalea-mark-light.svg — symbol only, 64px grid
- azalea-favicon.svg — symbol without center dot (reads at 16px)
- azalea-lockup-*.svg / azalea-stacked-*.svg — symbol + wordmark; text is live and imports Archivo from Google Fonts (works in browsers; use the PNGs where fonts can't load)
- *.png — rasterised lockups (2x / 4x) with the font baked in

Clear space: half the mark height on all sides. Don't recolor, rotate, or add effects.
